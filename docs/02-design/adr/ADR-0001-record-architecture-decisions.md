# ADR-0001：使用 ADR 记录架构决策

- 状态：已接受
- 日期：2026-10-19
- 决策人：Owner

## 背景
项目由多个 AI 助手轮流开发，口头约定和聊天记录无法在助手之间传递，导致重复讨论或相互推翻。

## 决策
凡涉及架构、依赖、接口契约、数据格式、目录结构、对外发布的决定，写一份 ADR（模板 `ai-collab/templates/adr.md`），编号递增，存放于 `docs/02-design/adr/`。ADR 一经接受不修改正文，只能被新 ADR 取代。

## 影响
助手在做此类改动前必须先查阅已有 ADR；与 ADR 冲突的改动需新 ADR 并经 Owner 批准。
