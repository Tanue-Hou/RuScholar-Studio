# ADR-0002：本地优先、可降级的混合判定引擎（追记）

- 状态：已接受（对既有设计的追记）
- 日期：2026-10-19
- 决策人：Owner

## 背景
用户的未发表论文属于敏感数据；同时本地小模型的判定质量有限，云端大模型质量好但涉及数据外发与费用。

## 决策
- 三种模式：`local`（全本地）、`hybrid`（本地 PPL + 云端判定）、`cloud`（全云端）；默认 `local`。
- 规则轨始终在本地运行；任何一层不可用时向下降级（无模型 → 纯规则），不能让整个诊断失败。
- 不输出单一 AI 率，所有结论附证据。

## 影响
新增能力必须说明在三种模式下的行为与降级路径；任何会把正文发往外部服务的改动必须在 UI 与文档中明示。
